# Linden (English course for Romanian speakers)

If `HANDOFF.md` exists locally, read it first. It holds the full context, the design proposal and the open decisions.

- **This repo is public.** Never commit private info: people's names or relationships, e-mail addresses, private links, local paths. `HANDOFF.md`, `design/` and `private/` are local-only and gitignored; keep notes like that there. Check staged files before every commit.
- **Deploy only when the user says so.** `npm run deploy` changes the app on real phones.
- **Tests and previews are silent.** Open the app with `?mute` (e.g. http://localhost:5180/linden/?mute); Playwright contexts get `addInitScript(silence)` from `tests/walk.mjs`. Never play the voice out loud.
- **The app** is an installable web app (PWA) built with Vite 6 (Node on this PC is 22.11; Vite 7+ needs 22.12). Live at https://paleferndev.github.io/linden/ from the `gh-pages` branch.
  - `npm run dev` serves on port 5180. `npm test` builds and checks everything: the content (`npm run test:content`, no browser), first open, the tabs at phone and desktop sizes in light and dark, all twelve episodes, a training session, every game and every entry of the exercise list played end to end at 390×844 and 320×568, offline start, and the self-update from build A to B. `node tests/walk.mjs <url> --shots [--big|--small] [episode n] [--extras]` screenshots every screen to `tests/shots/walk/` (with n, episodes 1…n). `tests/art.html` (on the dev server: `/linden/tests/art.html`) shows every drawing.
  - The walk answers by reading `window.__linden`, a hook the app sets only in automated browsers (`hook()` in `ui.js`): whatever screen asks for input says what it expects. New inputs must call `hook()` too.
  - `npm run deploy` refuses uncommitted changes, runs the tests, builds, commits `dist/` to `gh-pages`, pushes, and asks GitHub for a Pages build (a push alone doesn't always trigger one).
- **The season.** A cozy mystery on Linden Lane: the Stranger (a small figure in a coat and hat too big for it, face in shadow, two points of light, a lantern) lands in the garden of No. 1. Each of the 12 episodes gives back one of its sparks, teaches one grammar point (A2 → B1) and six verbs. It is a star; that is revealed only in episode 12. Episodes open in order.
- **Code map**
  - `src/content/`: `episodes/e01.js`…`e12.js` (each episode's script, written with the helpers in `dsl.js`), `episodes.js` (the season, and the window each episode lights), `grammar.js` (points, notes, practice banks), `verbs.js` (the verb album), `games.js` (each game's rounds), `cast.js` (who talks, their voice and reactions), `kinds.js` (the exercise list), `verbbook.js` (a page per verb: meanings with an example each, a tip, examples by tense, phrases, the mistakes Romanian speakers make), `lessons.js` (a lesson per grammar point: a gist, then visual blocks: forms, turn, formula, pair, grid, words, tip; examples and mistakes). The book is read at a glance: no prose, short Romanian (the content test counts the words), what matters marked with **x**. Content never imports drawing code; pictures are named by key (`src/art/art.js`).
  - `src/app/`: `store.js` (progress in localStorage key `linden`, `migrate()` forward-only, Leitner boxes over `g:<point>` and `v:<verb>`), `sound.js` (each person's voice, normal/slow, the small tones), `grade.js` (typed answers: strict for word forms, typos forgiven only in long words), `ui.js` (helpers, sheet, toast, `hook`).
  - `src/screens/`: `frame.js` (the full-screen frame), `episode.js` (cover → chat → ending), `chat.js` (the chat engine: messages, notes, voice notes, and every kind of reply), `games/` (`kit.js` shared, `boards.js` and `special.js` the twelve games), `signal.js` (the radio transmission), `ending.js`, `training.js` (Antrenament: a chat built from what is due, and free play), `home.js`, `collections.js` (album, verbs, memories), `catalog.js` (Profil → Exerciții), `pages.js` (Profil, first open), `install.js`, `book.js` (the verb pages and the lessons, in the sheet: opened from an underlined verb in the chat, "De ce?" after a wrong answer, a note's "Lecția", the verb album, Colecții → Gramatică).
  - `src/art/`: `lane.js` the street, `scenes.js` the café, the room at No. 1 and Priya's shop, `night.js` the garden, bus stop, No. 9 and the roof, plus the episode and album pictures, `stranger.js` the Stranger, its lantern, the sparks and Mr Moss, `people.js` the neighbours and Mimi, `props.js` the games' drawings, `icons.js`. `npm run icons` regenerates `public/icons/` from the leaf.
  - `src/pwa.js` applies new builds on open or return to foreground, unless `setBusy(true)` (something full screen is open).
  - All project sites of the GitHub user share one origin, so namespace every storage key with `linden`.
- **Voices.** The story's lines are recordings in `public/voices/<key>.mp3`, named by `voiceKey(who, text)` (`src/app/voicekey.js`) and listed in `src/content/voices.js` (generated). Each character speaks in a Supertonic 3 voice style, cloned by Chatterbox from a short sample of that voice in the line's mood; Whisper checks every take and only takes with exactly the script's words are kept. Lines without a recording use the phone's voice. The models live in a folder outside the repo (`LINDEN_VOICE_MODELS`: the Chatterbox environment `chatter/`, the Hugging Face cache `hf/`, the voice samples `refs/`). After changing lines: `node scripts/voices/export-lines.mjs <models>/lines.json`, then `<models>/chatter/Scripts/python scripts/voices/record.py` (only new or changed lines are recorded). The casting is `CAST` in `record.py`; the name lines' spoken text is `NAME_SAY` in `export-lines.mjs`.
- **Exercises must take effort.** Recall beats recognition; multiple choice only helps with competitive options; dictation transfers to real use. Every reply in the chat can be wrong: a wrong one is sent, the other person reacts, one Romanian line says why, and you try again. Wrong options are real mistakes of Romanian speakers. No matching pairs, no options that differ in everything, no pronunciation written as text, no speaking aloud (that comes later, as an optional module).
- **Writing an episode:** the entry types are listed in `dsl.js`. The first option of a task is the right one. Give tasks and notes their grammar point with `g(point, …)`: it is what "De ce?" and a note's "Lecția" open. Run `npm run test:content`, then `npm test` (the walk plays it at both phone sizes).
- **Copy:** the UI is Romanian and says only what's needed, plainly. No cute or cheerleading lines. English is always set in Besley (`.en`); if it's in the serif, it's English.
- **The old app** is `legacy/engleza.html`, with its tests (`npm run test:legacy` after `npm --prefix legacy/test install`).
- The design exploration is in `design/` (local only).
